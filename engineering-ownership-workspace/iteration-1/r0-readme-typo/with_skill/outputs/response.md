README 한 글자 오타 수정은 실제 diff가 문서 변경에만 한정됐다는 전제에서 **R0**입니다. 이 경우 change brief, ADR, runbook, teach-back은 필요하지 않습니다.

저장소를 연결해 주시면 전체 diff를 확인해 오타 외에 링크·명령 예시·코드 블록이 뜻밖에 바뀌지 않았는지 검토하겠습니다. 그 뒤 저장소에 정의된 Markdown lint나 링크 검사처럼 관련 있는 가벼운 검사 하나만, 실행 승인을 받은 뒤 현재 diff를 대상으로 새로 실행하겠습니다. diff와 검사 결과를 직접 확인하기 전에는 production-ready라고 보고하지 않겠습니다.
